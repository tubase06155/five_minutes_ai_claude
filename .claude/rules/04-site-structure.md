# Site Structure

## Pages

```
/           → Landing page (main)
/about      → About Fiveminutes AI / MediaX
/services   → All services overview
/blog       → Blog / articles (phase 2)
/contact    → Contact / demo request
```

## Landing Page — Thứ tự sections

1. **Navbar** — Logo trái, nav links giữa, CTA phải. Sticky, blur backdrop.
2. **Hero** — Headline lớn, subtext, 2 CTA (primary + ghost), social proof badges.
3. **Logos** — Dải logo đối tác / khách hàng.
4. **Features** — Grid 3 cột: icon + tên + mô tả năng lực.
5. **ProductShowcase** — Text trái + visual phải (code block / UI mockup), đan xen.
6. **Stats** — Headline mạnh + số liệu nổi bật / proof points.
7. **Testimonials** — 2–3 card quote khách hàng.
8. **Pricing** — 3 tier: Starter / Pro / Enterprise.
9. **CtaBanner** — Full-width, headline + CTA đơn.
10. **Footer** — Logo, nav columns, social links, địa chỉ MediaX, copyright.
